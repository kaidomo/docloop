# Default review axes

- State machine: transitions, terminal states, and impossible states.
- Counts and limits: maxima, boundary wording, candidates, and units.
- Terminology: canonical names and variants.
- Update behavior: source, cadence, overwrite/append semantics, and stale state.
- Cross-references: match duplicated tables/lists row by row and enumerate differences.
- Ambiguity: quantitative conditions, inclusive/exclusive bounds, pronoun/reference targets.
